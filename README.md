# Deskripsi
Website ini dibuat untuk memperkenalkan diri saya sebagai mahasiswa Teknologi Informasi melalui tampilan portfolio yang sederhana, responsif, dan mudah digunakan.
Project ini menerapkan HTML sebagai struktur halaman, CSS untuk styling dan responsive design, serta JavaScript untuk interaksi pada navigation menu.

**Features**
  - Responsive design untuk desktop, tablet, dan mobile
  - Navigation menu
  - Hero section
  - About Me
  - Skills
  - Project showcase
  - Experience
  - Contact section
  - Social media links
  - Mobile navigation menggunakan JavaScript DOM

**Teknologi**
  - HTML5
  - CSS3
  - JavaScript
  - DOM Manipulation

**Responsive Design**
Website dirancang agar dapat menyesuaikan tampilan pada:
  - Desktop
  - Tablet
  - Mobile
  - Small mobile

**JavaScript / DOM**
JavaScript digunakan untuk membuat navigation menu pada tampilan mobile.
Interaksi dilakukan menggunakan:
  - getElementById()
  - addEventListener()
  - classList.toggle()
  - classList.contains()
  - setAttribute()
